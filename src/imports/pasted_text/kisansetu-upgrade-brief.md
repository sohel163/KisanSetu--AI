4. PRIMARY USER
==================================================

Design primarily for Indian farmers.

Assume the user may:

• Have limited technical experience
• Prefer simple language
• Use regional languages
• Use voice input
• Have limited time
• Need confidence before selling
• Care strongly about payment security
• Need clear financial information

Therefore:

• Keep screens simple
• Use large touch targets
• Avoid complicated menus
• Avoid technical terminology
• Use icons + labels
• Make important actions obvious
• Use short sentences
• Use realistic agricultural data
• Never overload the screen
